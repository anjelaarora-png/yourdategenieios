# Your Date Genie — Event Production Checklist

**Use this for every Your Date Genie event** (launch parties, singles meetups, group dates, workshops, panels). Print or pull up on phone. Tick boxes as you go.

---

## T-30 days — Foundations

### Insurance and legal

- [ ] Get a quote and bind General Liability coverage ($1M/$2M minimum). Vendors: eventsured.com · theeventhelper.com · gatherguard.com
- [ ] If alcohol is served by anyone other than a licensed venue: add liquor liability rider.
- [ ] Request Certificate of Insurance (COI) listing the venue as "additional insured." Send to venue.
- [ ] Confirm venue's own liability coverage and that they handle liquor service if alcohol is involved.
- [ ] Verify your LLC's insurance binder is in your business email folder, not just personal.

### Venue contract

- [ ] Read the venue contract end-to-end. Highlight: cancellation policy, deposit refund timeline, force majeure, hold-harmless clauses.
- [ ] Negotiate or strike any clause that requires YDG to indemnify the venue for the venue's own negligence.
- [ ] Confirm capacity, parking, ADA accessibility, restrooms, smoking policy, noise ordinance cutoff.
- [ ] Pay deposit. Save receipt.

### Marketing and registration

- [ ] Choose ticketing platform (Eventbrite, Partiful, Luma). Set up event page.
- [ ] Add event title, date, time, address, ticket price, refund policy, age requirement, what's included, what's NOT included.
- [ ] Embed waiver acceptance in the registration flow OR plan to collect at the door.
- [ ] Set up a Google Form for emergency contact + dietary restrictions if not captured at ticketing.
- [ ] Promo plan: IG post, IG story, TikTok, Reddit (relevant subreddits only — read each sub's self-promo rules).
- [ ] Email YDG users in the city about the event.

---

## T-14 days — Logistics lock

### Vendors and supplies

- [ ] Confirm all third-party vendors: photographer, DJ/music, florist, caterer, signage printer.
- [ ] Lock vendor payment terms in writing (deposit + final balance + cancellation cost).
- [ ] Order printed materials: name tags, table tents, waivers (paper backup), Code of Conduct posters.
- [ ] Order branded swag if applicable (lead time 7–10 days for most printers).
- [ ] Confirm A/V needs with venue: mic, speakers, projector, Wi-Fi password.
- [ ] Build the run-of-show document (timeline + who's responsible for each segment).

### Attendee experience

- [ ] Send confirmation email to all registered attendees with: address, parking/transit, dress code, what to bring, age requirement reminder, refund cutoff.
- [ ] Build an attendee spreadsheet with: name, email, phone, emergency contact, allergies, dietary notes, payment status, waiver status.
- [ ] Decide on attendee badging system (color wristbands for: attendee · staff · no-photo opt-out · 21+ if alcohol).

### Safety planning

- [ ] Designate one person as **Safety Host**. They wear a distinctive color wristband. Their job: handle conflict, harassment complaints, medical issues, intoxicated guests.
- [ ] Identify nearest hospital, urgent care, and 24-hour pharmacy. Save addresses on the run-of-show.
- [ ] Build a kit: first-aid kit, ice packs, paper waivers, extra pens, sharpie, gaffer tape, zip ties, phone charger.
- [ ] If alcohol is served: pre-arrange rideshare partnership (Uber/Lyft promo code) OR plan Lyft vouchers for visibly impaired guests.

---

## T-7 days — Tightening

### Final headcount and venue

- [ ] Send venue final headcount and any setup specifics (table count, chair count, AV).
- [ ] Confirm caterer's allergen-handling and final menu. Cross-check against attendee dietary notes.
- [ ] Confirm photographer arrival time and shot list (wide shots for marketing — get model releases via the waiver).
- [ ] Walk-through of the venue if local. Photograph the space. Note any hazards (cords, steps, low ceilings).

### Marketing push

- [ ] Last big social push: IG carousel post, TikTok, Story countdown sticker.
- [ ] Email reminder to registered attendees with arrival logistics.
- [ ] Reply to any registration questions in inbox.
- [ ] If under-sold: open up a small "+1 for free" or discount code to fill the room.

### Day-of paperwork

- [ ] Print: 2x master attendee list, 30+ blank waivers, sign-in sheet, Code of Conduct posters (8.5x11), name tags.
- [ ] Charge a backup phone or tablet to use as a backup check-in device.
- [ ] Build a shared Google Drive folder for event photos so the photographer can drop files day-of.

---

## T-1 day — Final prep

- [ ] Confirm with venue: setup time, contact name + cell, security/door staff names, fire marshal capacity.
- [ ] Confirm with all vendors: arrival time, contact cell, special requests.
- [ ] Pack the event kit (see T-14 list). Do NOT leave waivers, name tags, or first-aid kit at home.
- [ ] Check weather forecast. If outdoor or partial-outdoor, have a contingency.
- [ ] Charge: phone, backup phone, photographer's batteries, mic batteries.
- [ ] Set out tomorrow's outfit. (Trust me — day-of-event is chaotic.)
- [ ] Send team a final group text with run-of-show, addresses, and emergency contacts.

## Post-event — Within 48 hours

- [ ] Pay any outstanding vendor balances.
- [ ] Photographer delivers raw files; back them up to Drive AND a second cloud (in case Drive auth breaks).
- [ ] Send thank-you email to attendees with: photos, social tag request, post-event survey link, next-event signup.
- [ ] Email the highest-engagement attendees personally (the people who DM'd, asked questions, brought friends). Future ambassadors.
- [ ] Post recap content: IG carousel, TikTok recap, Story highlight.
- [ ] Update the attendee spreadsheet: who came, who flaked, conduct flags (positive AND negative).
- [ ] Internal debrief with the team: 3 things that worked, 3 things to fix, 1 thing to never do again.
- [ ] Reconcile the books: total revenue, total cost, net P&L. Save to your bookkeeping tool.
- [ ] File all signed waivers in a labeled folder (physical) AND scan to Drive (digital). Retain for **at least 3 years** for liability/insurance purposes.
- [ ] If anything went wrong: write a brief incident report (date, time, what happened, who was involved, what was done). Send to your insurance agent if material.

## Recurring red-flag list — do NOT ignore

1. **No proof of insurance from a vendor or the venue.** No COI = no event. Not negotiable.
2. **Self-pour or BYOB events.** Massive liquor liability. Use licensed venues only for v1.
3. **Skipping waivers because it "feels weird."** Waivers are how you sleep at night when something goes wrong. Get them signed.
4. **Letting an obviously-intoxicated guest drive home.** Rideshare them. This is a moral and legal must.
5. **Ignoring a harassment complaint to "keep the vibe."** Pull the offender out immediately. Document. Refund if it's the lesser evil.
6. **Photo-publishing without consent flags.** Always cross-check the no-photo wristband list before posting recap content.
7. **Cash-only ticketing.** Use a platform with a paper trail (Eventbrite, Partiful, Luma) for tax + dispute reasons.
8. **Skipping the post-event debrief.** Each event compounds your operational know-how only if you write things down.
